# SQL

SQL‑скрипти для побудови та підтримки Data Warehouse.

## Структура

- **ddl/** — створення таблиць, індексів, constraints.
- **staging/** — таблиці та логіка завантаження сирих даних.
- **dim/** — таблиці вимірів.
- **fact/** — факт таблиці.
- **views/** — представлення для аналітики та ETL.

## Призначення

Використовується для версіонування SQL‑логіки та автоматизації деплою.
