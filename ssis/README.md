# SSIS

Директорія містить артефакти SQL Server Integration Services.

## Структура

- **projects/** — .dtproj файли та структура SSIS‑проєктів.
- **packages/** — окремі .dtsx пакети.
- **configs/** — конфігураційні файли (XML, JSON, environment configs).
- **parameters/** — параметри пакетів та проєктів.

## Призначення

Використовується для зберігання, версіонування та деплою SSIS‑пакетів через CI/CD.
