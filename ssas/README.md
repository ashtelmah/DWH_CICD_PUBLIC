# SSAS

Артефакти SQL Server Analysis Services (Multidimensional / Tabular).

## Структура

- **multidimensional/** — структури кубів, measure groups, dimensions.
- **xmla/** — XMLA‑скрипти для деплою моделей.
- **partitions/** — конфігурації партицій.
- **aggregations/** — агрегації та оптимізаційні структури.

## Призначення

Використовується для автоматизації деплою SSAS‑моделей через CI/CD.
