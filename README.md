# DWH_CICD
CI / CD process for SSIS and SSAS

Цей репозиторій містить повну структуру для побудови CI/CD процесів у Data Warehouse середовищі, включаючи SSIS, SSAS, SSRS, SQL‑скрипти, тестування та автоматизацію деплою.

## Структура репозиторію

- **ssis/** — пакети, проєкти, конфіги та параметри SSIS.
- **ssas/** — моделі, XMLA‑скрипти, партиції та агрегації SSAS.
- **ssrs/** — звіти, data sources та datasets SSRS.
- **sql/** — DDL, staging, DIM, FACT, views.
- **processing/** — логіка обробки SSIS/SSAS.
- **ci/** — CI‑пайплайни для SSIS/SSAS/SSRS.
- **cd/** — CD‑пайплайни та оркестрація деплою.
- **tests/** — SQL, MDX та SSIS тести.
- **docs/** — архітектура, стандарти, пайплайни.

Проєкт орієнтований на автоматизацію деплою та контроль якості у DWH середовищі.
